# Dr. Bikash Barman — Academic Website

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile menu and current year

## How to use
1. Open `index.html` in a browser to preview it.
2. Replace `your-email@example.com` with your email.
3. Replace the `#` social/research links with your Google Scholar, ORCID, ResearchGate, etc.
4. Replace the sample publication entries with your complete publication list.
5. Add PDF files later inside a `resources/` folder and update the links.

## Free hosting
The site is static and can be hosted free on GitHub Pages, Cloudflare Pages, or Netlify.
